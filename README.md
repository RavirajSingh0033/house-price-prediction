# House Price Prediction using Machine Learning

## Project Overview
This project predicts house prices based on area and number of bedrooms using Machine Learning.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-Learn

## Machine Learning Algorithm
- Linear Regression

## Features
- House price prediction
- User input based prediction
- Machine Learning model training

## Project Files

- app.py
- house_data.csv
- README.md
- requirements.txt

## How to Run

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the project:

```bash
python app.py
```

## Sample Input

Area: 1700

Bedrooms: 3

## Sample Output

Predicted Price: 8500000
